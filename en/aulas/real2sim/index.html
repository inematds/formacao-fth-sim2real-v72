Lesson 7 · 14 min

Real-to-sim: bringing the real world into the simulator

So far the path has gone from the simulator to the robot. The reverse path exists too: photograph the real place and build a twin where the robot trains and is tested first. In this lesson you run the twin from the robotica-real2sim project (an arm, not a humanoid) in the course venv and prove a plan in the physics, and you see where this stands for humanoids in 2026.

Goal: run the robotica-real2sim twin in the course venv and prove a plan in the physics before the robot, counting the objects in the scene.

02 · What about humanoids?

Status as of Oct 2026, according to the program's research. Click each item.

1. Gaussian splatting

Niantic Spatial, Flexion and NVIDIA showed a scene scanned by camera turning into Gaussian splatting in Isaac Sim, with a humanoid navigation policy trained there and taken to the robot with no tuning. This is vendor material, not a paper with measurements.

2. GaussGym

Berkeley, ETH and Amazon FAR use 3DGS as a renderer inside a vectorized simulator, at 100k+ steps per second (arXiv 2510.15352). Also with no measured sim-to-real on a humanoid as of Oct 2026, according to the research.

3. What is already routine

What already makes it into day-to-day work is simpler: measuring the floor and the friction, weighing the robot, scanning steps and obstacles for the terrain curriculum (course 1).

4. For you

A twin (digital twin) is only as good as the measurement that feeds it. The real2sim project measured this: different vision models got the tray size wrong, and the proof only approves what passes in the worst case.

03 · Run the twin and the proof

Adds the Panda to the bench's Menagerie sparse-checkout, pins robotica-real2sim to the tested commit and points its vendor/menagerie to yours.

Terminal · desk twin (digital twin)
F=${FTH:-$HOME/fth}; cd $F && . .venv/bin/activate && pip install -q pillow imageio
git -C mujoco_menagerie sparse-checkout add franka_emika_panda
[ -d robotica-real2sim ] || git clone -q https://github.com/inematds/robotica-real2sim
git -C robotica-real2sim checkout -q 3a08537 && mkdir -p robotica-real2sim/vendor
ln -sfn $F/mujoco_menagerie robotica-real2sim/vendor/menagerie
cd robotica-real2sim && python3 r2s.py ver exemplos/mesa-foto/cena.json $F/gemeo.png --camera cima
python3 $F/sim2real/kit/gemeo.py exemplos/mesa-foto/cena.json $F/gemeo.png
Terminal · prove the plan (20 variations)
F=${FTH:-$HOME/fth}; cd $F/robotica-real2sim && . $F/.venv/bin/activate
python3 r2s.py provar exemplos/mesa-foto/cena.json resultados/mesa-foto/plano.json -n 20 | tail -3
